    Release Notes¶

    v0.2.0 — Open-Core Release¶

    The first published open-core release. It ships the standalone verity-redteam-core distribution with the workstation scanner, the free CLI (scan, test, serve), the deterministic SQL AST guard, and the four zero-Docker targets. The release was verified inside empty containers from both the built wheel and PyPI.

    v0.2.1 — Hardening Patch¶

    A hardening patch on top of the 0.2.0 surface. It tightens credential-shape detection, dialect-aware SQL validation, offline and air-gapped behaviour, and the reporting/parity guards that keep the documentation honest.

    Customer Upgrade Guide¶

    Upgrade the CLI distribution in place:

    pip install --upgrade verity-redteam-core

    Run the latest scanner without installing it:

    uvx --from verity-redteam-core verity scan

    After upgrading, re-run your CI gate with the same policy flags. The rule ids are stable, so existing suppressions and baselines continue to apply. New rules added in this window are additive: they never reuse an existing id, so a green build only turns red when a genuine new finding appears.
