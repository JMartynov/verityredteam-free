    Verity RedTeam Free v0.2.0¶

    PyPI Package: verity-redteam-core==0.2.0
    License: Apache-2.0
    Python: >=3.12,<3.15

    pip install verity-redteam-core==0.2.0
# or run zero-install via uvx:
uvx --from verity-redteam-core==0.2.0 verity scan

    What's New (M7–M11)¶

    M7: CLI Parity, ConsolidatedSecurityAuditor Wiring & YAML Config Support¶

    • Wired ConsolidatedSecurityAuditor into verity scan (workstation discovery and --config-file) for plaintext secret scrubbing (SEC-STATIC-SECRET-IN-CONFIG), shell wrapper checks (SEC-STATIC-UNSAFE-SHELL-WRAPPER), Passport fingerprinting, and offline OSV CVE correlation (VULN-*).
    • Added YAML parsing support for .continue/config.yaml and librechat.yaml in MultiClientConfigScanner and verity scan.
    • Updated ActiveExploitBridge.DEFAULT_CLI_COMMAND_TEMPLATE to valid verity CLI flags and aligned _load_sarif_exporter() entry-point discovery.

    M8: Ground-Zero Empty-Container E2E Customer Verification Suite¶

    • Added a clean-room 4-container verification suite under tests/e2e_containers/ (customer-pip, customer-uvx, customer-full-workstation, and target-sse-lab) supporting both INSTALL_SOURCE=wheel and INSTALL_SOURCE=pypi.
    • Verified 6 end-to-end customer scenarios (verify_all_scenarios.sh) against both real vulnerable MCP packages (mcp-remote@0.1.15, DVMCP) and deterministic fixtures, producing sanitized output snapshots under tests/e2e_containers/snapshots/.

    M9: Dynamic, Narrow Terminal Screencast GIF (docs/assets/demo.gif)¶

    • Replaced the oversized static SVG with a reproducible, compact (860x440) animated terminal screencast (docs/assets/demo.gif) generated via Charmbracelet VHS in Docker (scripts/record_demo_gif.sh, docs/assets/demo.tape) and optimized with gifsicle.

    M10: Customer-Focused README.md Restructure & CLI Documentation Parity Guard¶

    • Restructured README.md around real AppSec/developer pain points with container-verified command outputs, capability tables, CI snippet, and Free vs. Enterprise comparison.
    • Moved plugin entry_points boilerplate to docs/extensibility.md and added tests/unit/test_documentation_parity.py to enforce CLI and documentation parity.

    M11: Credential Detection Hardening, Packaging/Display Polish & v0.2.0 Release¶

    • Added MultiClientConfigScanner.DSN_CREDENTIAL_PATTERN and shared is_secret_env_entry() across config_scanner.py, auditor.py, and cli.py to flag embedded DSN credentials and SECRET_VALUE_PATTERNS under arbitrary env keys while keeping ${VAR} placeholders exempt.
    • Scrubbed embedded DSN passwords across terminal, json, markdown, and html reports.
    • Modernized pyproject.toml to SPDX license = "Apache-2.0" with setuptools>=77.0.0, added no_wrap=True to the Rule column in terminal.py, and bumped verity-redteam-core to 0.2.0.
