    Local-vs-CI Gaps in verityredteam-free¶

    1. scripts/ Not Linted in CI: ci.yml and full-tests.yml run ruff check src tests rather than ruff check src tests scripts (unlike the local developer baseline).
    2. Portal Drift Caught Post-Merge: scripts/build_docs_portal.py --check runs only in pages.yml on main push, not in ci.yml on pull requests.
    3. Partial Workflow Hygiene Coverage: tests/unit/test_workflow_hygiene.py hardcodes 5 files in ALL_WORKFLOW_PATHS, omitting pages.yml (and any future upstream-sync.yml).
    4. Hardcoded "0.2.2" in Container E2E & Parity Tests: tests/e2e_containers/Dockerfile.customer-pip:13, Dockerfile.customer-uvx:9, Dockerfile.customer-workstation:22, verify_all_scenarios.sh:171, and tests/unit/test_cli_auditor_parity.py:530 hardcode "0.2.2", creating manual release drift.
    5. No Automated Upstream Sync: verityredteam-free has no .github/workflows/upstream-sync.yml to refresh uv.lock and src/verity/data/*.json.gz when upstream mcp-fingerprints / mcp-vulnerabilities release.

    4. Root-Cause Diagnosis of Failing & Incomplete Flows¶

    1. Update Homebrew Tap Failure (45914244097):
    2. secrets.HOMEBREW_TAP_TOKEN is unset in JMartynov/verityredteam-free, so actions/checkout@v5 fails with Input required and not supplied: token.
    3. When Publish to PyPI runs via workflow_dispatch on main, github.event.workflow_run.head_branch evaluates to "main", causing PyPI lookup of verity-redteam-core/main/json to fail.
    4. homebrew-tap.yml does not pass --from-lock to scripts/generate_homebrew_formula.py and does not validate Formula/verity.rb with ruby -c.
    5. Empty v0.2.2 GitHub Release & Manual PyPI E2E:
    6. workflow.yaml publishes to PyPI only, leaving GitHub Release v0.2.2 with assets: [] and requiring manual runs for INSTALL_SOURCE=pypi container verification.
    7. Upstream mcp-fingerprints Daily Sync Rejection (45983774823):
    8. web/catalog.json exceeded GitHub's 100.00 MB file limit (101.30 MB), rejecting git push since Nov 24 and preventing downstream repository_dispatch (which also lacks REPO_DISPATCH_PAT and sends mismatched fingerprints_version instead of upstream_version).
    9. Upstream mcp-vulnerabilities Asset & Scheduling Gaps:
    10. v* GitHub Releases (v1.7.44) omit vulnerabilities.json.gz, sign_release.yml dispatch omits --ref "v${NEW_VERSION}", and cross_repo_sync.yml runs at 0 4 * * * simultaneously with mcp-fingerprints.
